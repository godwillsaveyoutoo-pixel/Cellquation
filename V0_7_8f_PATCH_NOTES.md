# Cellquation Core v0.7.8f — Live Semantic Menu Miniatures

## Menu campaign art
- Removed the old semantic campaign composition made from HUD PNG cells.
- Foundations now renders three disconnected cells with the real CellKit WebGL renderer.
- Living Networks now renders a four-node mini network with the real CellKit cell renderer and the real SynapseRenderer.
- Two-colour and three-colour menu modes feed their actual species palette into the live miniatures.
- Campaign icon area increased to 84×84 px on the regular home layout, with responsive 76 px / 68 px variants.
- Live menu canvases are performance-limited: 1× pixel ratio, reduced detail, ~14 fps; reduced-motion receives a static frame.

## Colour selector
- Replaced abstract outlined colour dots with the same nucleus-free target-cell artwork used in the gameplay goal HUD.
- 2 COLOURS shows blue + green target cells.
- 3 COLOURS shows blue + green + violet target cells.

## Preserved systems
- v0.7.8e persistent audio shell and Scott Buckley default track are unchanged.
- v0.7.8d Brood count visual fix is preserved.
- v0.7.8c Fusion source → target semantics are preserved.
- v0.7.8b dual-orientation Living Networks layouts are preserved.
- Settings/background/audio continuity logic is unchanged.
