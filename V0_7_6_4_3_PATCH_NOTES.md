# Cellquation Core v0.7.6.4.3 — Developer Mode Navigation Fix

## Fixed
Developer Mode no longer disappears when entering a world or starting a level.

The cause was timing: world cards and level links are generated by deferred ES modules after the developer helper initially scanned the page. Those late-created URLs therefore lacked `dev=1`.

## New navigation contract
- existing internal links receive `dev=1` and the selected `devq` tier;
- dynamically inserted links are handled through a `MutationObserver`;
- every tapped/clicked internal link is decorated once more immediately before navigation;
- AUTO removes only `devq`, while Developer Mode itself remains active;
- external links are left untouched.

No gameplay, renderer quality, cell material, animation, campaign, or aesthetic-preset rules were changed.
