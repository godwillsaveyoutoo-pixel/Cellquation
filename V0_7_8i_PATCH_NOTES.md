# Cellquation Core v0.7.8i — Ratio Clarity

A final onboarding clarity pass. Gameplay HUD remains unchanged and minimal.

## Changes
- Added a one-time informational first step to both Foundations tutorials explaining that goals are **ratios/proportions, not exact totals**.
- 2-colour example: `1 : 2 = 2 : 4 = 3 : 6`.
- 3-colour example: `1 : 2 : 1 = 2 : 4 : 2`.
- Added a subtle reminder under the first world's intro only while the campaign has zero completed levels.
- The reminder disappears automatically after the player completes a level.
- No `RATIO` / `TARGET RATIO` label was added to gameplay. The target HUD remains visually unchanged.
- Fresh physical tutorial/menu script names and a new CSS filename are used to avoid stale service-worker assets.
- Service-worker cache bumped to `cellquation-v0.7.8i`.
